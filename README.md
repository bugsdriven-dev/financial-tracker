## 📖 About

WealthTracker is a personal finance tracking application that lets users record and categorise their income and expenses in real time. Built during a Fullstack Web Development internship at **Unified Mentor**, it was my first end-to-end full-stack project — from designing the APIs to deploying a live, working product.

## ✨ Features

- Add, view, and categorise income and expense entries
- Real-time updates between frontend and backend
- Clean, responsive interface for tracking financial records
- REST API layer connecting client and server

## 🛠️ Tech Stack

**Frontend:** React
**Backend:** Node.js, Express
**API:** REST
**Deployment:** Vercel

## 📁 Project Structure

```
financial-tracker/
├── client/     # React frontend
├── server/     # Node.js/Express backend
└── .gitignore
```

## 🚀 Getting Started

1. Clone the repository
   ```bash
   git clone https://github.com/bugsdriven-dev/financial-tracker.git
   cd financial-tracker
   ```
2. Install dependencies in both folders
   ```bash
   cd client && npm install
   cd ../server && npm install
   ```
3. Set up environment variables (API URL, client URL, etc.) as required by `client/` and `server/`
4. Run the client and server
   ```bash
   # In client/
   npm start

   # In server/
   npm start
   ```
